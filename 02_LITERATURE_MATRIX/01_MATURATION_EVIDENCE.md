# Maturation Program — Evidence v1

## Purpose

This program is intended to capture general neuronal / synaptic maturation while remaining separate from dopaminergic identity.

Dopaminergic-specific genes such as TH, DDC, SLC6A3, SLC18A2, NR4A2 and PITX3 are deliberately excluded from this program and will be evaluated separately in the Dopaminergic Identity / Integrity program.
