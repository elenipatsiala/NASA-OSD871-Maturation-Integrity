# NASA OSD-871 Maturation–Integrity Analysis

A preregistered analysis testing whether LEO-associated transcriptional maturation in human dopaminergic organoids is accompanied by preservation of dopaminergic identity and integrity.

This project extends the original NASA OSD-871 reproduction Build by separating:

- neuronal maturation,
- dopaminergic identity / integrity,
- progenitor / cell-cycle state,
- cellular stress,
- astroglial and microglial annotations.

The central question is:

**Does a transcriptional shift toward maturation also preserve the biological fidelity required for a useful dopaminergic disease model?**
