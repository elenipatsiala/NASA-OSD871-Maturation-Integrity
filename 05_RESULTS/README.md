# Iterate Results

This folder contains the main outputs from the maturation-versus-integrity analysis.

Primary result tables include:

- preregistered gene availability,
- sample-level biological program scores,
- Ground-versus-LEO summaries,
- subgroup summaries,
- maturation–integrity shifts,
- leave-one-gene-out sensitivity results,
- curated Hallmark pathway evidence.

Intermediate files are kept only when they are required for reproducibility.
