# ITERATE Preregistration — v1

## Central Question

Does the LEO-associated transcriptional maturation phenotype in human dopaminergic organoids reflect biologically useful maturation while preserving dopaminergic identity and integrity, or can the pattern be explained by altered progenitor/cell-cycle state, stress, or glial/cellular-composition changes?

## Predeclared Biological Programs

The analysis will define and freeze literature-derived gene sets for:

1. Neuronal maturation
2. Dopaminergic identity / integrity
3. Progenitor / cell-cycle state
4. Stress / glial state

## Rules Before Scoring

- Gene sets must be supported by published literature.
- Initial gene sets will be frozen before inspecting new program-score results.
- Genes will not be removed because they produce an inconvenient result.
- Alternative gene sets will be treated as sensitivity analyses rather than replacements for the preregistered set.
- The same scoring rule will be applied across all samples.
- Disease-specific claims will not be made because disease status is confounded with donor/cell line in OSD-871.
- LEO-associated effects will not automatically be attributed specifically to microgravity.
- Program scores will be treated as exploratory biological summaries, not validated biomarkers.

## Falsification Principle

A useful-maturation interpretation should become weaker if maturation-associated signal increases while dopaminergic identity decreases or stress/glial dysregulation increases substantially.
