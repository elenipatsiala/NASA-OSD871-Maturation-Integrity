# Iterate Analysis Code

This folder contains the reproducible R scripts used for the maturation-versus-integrity analysis, robustness testing and pathway-level evidence.

The main analysis sequence is:

1. Gene availability audit
2. Preregistered program scoring
3. Maturation–Integrity map
4. Polished LEO NeuroTune map
5. Leave-one-gene-out sensitivity analysis
6. Curated Hallmark pathway evidence
